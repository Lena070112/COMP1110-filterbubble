# Annotation protocol (to be written with Zhao Dingcheng)
- Issue + claim definition (e.g. claim `strict_only`: "strict discipline is the only effective way")
- Stance labels: strict / balanced / alt / unknown — rules for each, with 2 examples each
- Reason inventory per issue (source for every reason; reference corpus is limited, not 'balanced')
- Evidence field: supporting passage or timestamp for every label
- Disagreement handling: alternative plausible labels recorded, then joint review
